# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

Participants are expected to keep discussions respectful, focused on the work,
and free of harassment, abuse, personal attacks, or disclosure of private
information.

Report unacceptable behavior privately through the security/contact channel in
`SECURITY.md`. Maintainers may remove content, close discussions, or block
participants when needed to keep the project usable.
